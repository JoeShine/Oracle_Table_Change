快速部署步骤（Windows 系统）

═══════════════════════════════════════════════════════════════

方法一：使用打包后的 exe（推荐用于最终部署）

1. 在 Windows 系统上运行 package.bat
   或手动执行：
   pyinstaller DBForge.spec --clean

2. 找到生成的 exe 文件：
   dist\DBForge.exe

3. 数据库客户端配置（按需）：
   - Oracle: 下载 Oracle Instant Client，按照 ORACLE_CLIENT_SETUP.txt 说明配置
             （仅在使用 thick 模式时需要；oracledb thin 模式无需此步骤）
   - MySQL : 无需额外系统依赖（pymysql 纯 Python 驱动）
   - SQL Server: 安装 Microsoft ODBC Driver 17 for SQL Server

4. 运行程序：
   双击 DBForge.exe

───────────────────────────────────────────────────────────────

方法二：使用 Python 源码（适合开发和测试）

1. 确保已安装 Python 3.8+

2. 安装依赖：
   运行 install.bat
   或手动执行：
   pip install -r requirements.txt
   pip install pymysql pyodbc          # 多数据库驱动（MySQL + SQL Server）

3. 数据库客户端配置（同上，按需）

4. 运行程序：
   python main.py

使用方法

═══════════════════════════════════════════════════════════════

第一步：配置连接管理
   1. 点击 "添加连接"
   2. 选择数据库类型（Oracle / MySQL / SQL Server）
   3. 填写连接信息：主机地址、端口、服务名/数据库名、用户名、密码
      - Oracle    : host:port/service_name   e.g. 192.168.1.100:1521/ORCL
      - MySQL     : host:port/database        e.g. 192.168.1.100:3306/mydb
      - SQL Server: host[:port]/database      e.g. 192.168.1.100:1433/MYDB
   4. 点击 "测试连接" 验证
   5. 保存连接

第二步：准备 Excel 文件
   Excel 格式要求：
   ┌──────────┬─────────────────────┐
   │ 唯一标识  │ 待修改数据            │
   ├──────────┼─────────────────────┤
   │ ID001    │ new_email@test.com  │
   │ ID002    │ new_email2@test.com │
   └──────────┴─────────────────────┘

第三步：执行更新
   1. 选择连接管理
   2. 输入目标表名（如：USER_INFO）
   3. 输入唯一标识列名（如：USER_ID）
   4. 输入待修改列名（如：EMAIL）
   5. 选择 Excel 文件
   6. 点击 "开始更新"
      注意：SQL 方言会随数据库类型自动切换

第四步：查看结果
   - 查看日志了解更新情况
   - 如有失败记录，会弹窗显示
   - 导出失败记录或完整日志

常见问题

Q: 程序启动报错 "找不到 Oracle 客户端库"？
A: 如仅使用 MySQL/SQL Server，可忽略此提示；如需使用 Oracle，请按 ORACLE_CLIENT_SETUP.txt 配置 Oracle Instant Client

Q: 程序启动报错 "找不到 pyodbc 或 ODBC Driver 17"？
A: 如仅使用 Oracle/MySQL，可忽略此提示；如需使用 SQL Server，请安装 Microsoft ODBC Driver 17 for SQL Server

Q: 连接测试失败
A: 检查主机地址、端口、服务名/数据库名、用户名、密码是否正确

Q: 更新失败怎么办
A: 查看日志了解失败原因，备份表已保存在对应 Schema/Database 中
