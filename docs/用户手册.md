## 1. 产品介绍

### 1.1 产品简介

Oracle数据批量修改工具是一款简单易用的数据库批量更新工具，通过Excel文件导入数据，实现Oracle数据库表的批量更新操作。

### 1.2 主要功能

- ✅ 数据库连接管理（支持多个连接配置）
- ✅ Excel数据导入（支持.xlsx/.xls格式）
- ✅ 数据预览（显示前50行）
- ✅ 多列同时更新
- ✅ 自动备份机制
- ✅ 失败自动回滚
- ✅ 操作日志和审计
- ✅ 历史记录管理
- ✅ 三套主题风格切换（默认深墨琥珀，另含 Idea 蓝色、清爽浅色，每套 30 个配色键，各支持深浅色模式，主题持久化）
- ✅ 快捷键支持

### 1.3 应用场景

- 批量修改员工信息
- 批量更新价格数据
- 批量同步基础数据
- 数据修正和清洗
- 定期批量数据更新

### 1.4 系统兼容性

| 发布方式 | Windows 7 | Windows Server 2008 R2 | Windows 10+ | Windows Server 2016+ |
|---------|-----------|------------------------|-------------|----------------------|
| exe打包 | ✅ 支持 | ✅ 支持 | ✅ 支持 | ✅ 支持 |

## 2. 安装配置

### 2.1 系统要求

| 配置 | 要求 |
|-----|------|
| 操作系统 | Windows 7及以上 / Windows Server 2008 R2及以上 / macOS / Linux / 麒麟V10 |
| 内存 | 2GB以上 |
| 硬盘 | 500MB以上 |
| Oracle Client | 需要安装Oracle Instant Client（或使用已安装的Oracle客户端） |

### 2.2 安装方式

#### 方式一：exe打包（推荐）

1. 下载 `OracleBatchUpdater.exe`
2. 双击运行即可

#### 方式二：便携版

1. 下载 `OracleBatchUpdater_Portable_v2.8.0.zip`
2. 解压到任意目录
3. 双击 `OracleBatchUpdater_Portable.bat` 运行

便携版优势：
- 无需管理员权限
- 可放在U盘运行
- 数据完全隔离

#### 方式三：Docker（仅适用于 Windows 10+ / Server 2016+）

```bash
docker-compose up -d
# 浏览器访问 http://localhost:6080
```

### 2.3 Oracle客户端配置（可选）

**重要说明：使用Easy Connect方式，无需配置任何文件！**

#### 方式A：使用已安装的Oracle客户端（推荐）

如果服务器已安装Oracle数据库或客户端：

- **无需额外安装Instant Client**
- **无需配置tnsnames.ora**
- 直接在工具界面输入连接参数即可

#### 方式B：安装Oracle Instant Client（可选）

1. 下载Oracle Instant Client
   - 访问：https://www.oracle.com/database/technologies/instant-client/downloads.html
   - 选择对应操作系统的版本（Basic或Basic Light）

2. 解压到目录，例如：
   - Windows: `C:\oracle\instantclient_19_8`
   - Linux: `/opt/oracle/instantclient_19_8`

3. 配置环境变量：
   - Windows: 在系统环境变量PATH中添加：`C:\oracle\instantclient_19_8`
   - Linux/macOS: `export LD_LIBRARY_PATH=/opt/oracle/instantclient_19_8:$LD_LIBRARY_PATH`

## 3. 快速入门

### 3.1 三步上手

#### 第一步：配置数据库连接

1. 切换到「数据库连接」标签页
2. 点击「+ 添加连接」
3. 填写连接信息（Easy Connect方式）：
   - 连接名称：给连接起个名字（如：开发环境）
   - 主机地址：数据库服务器地址
   - 端口：默认1521
   - 服务名：Oracle服务名
   - 用户名：数据库账号
   - 密码：数据库密码
4. 点击「测试连接」验证配置
5. 保存配置

**Easy Connect连接字符串格式：**
```
host:port/service_name
示例：192.168.1.100:1521/ORCL
```

#### 第二步：准备Excel数据

1. 使用提供的模板：`Oracle数据批量修改工具_导入模板.xlsx`
2. 按格式填写数据：
   - 第1列：唯一标识（如：员工ID）
   - 第2列起：要更新的列
3. 保存Excel文件

**注意：空字段将保留目标表原值，不会被更新为NULL**

示例：
```
EMP_ID | EMP_NAME | AGE | DEPT
-------|----------|-----|-------
1001   | 张三     |     | 技术部    ← AGE为空，保留原值
1002   | 李四     | 30  |           ← DEPT为空，保留原值
```

#### 第三步：执行更新

1. 切换到「当前配置」标签页
2. 填写配置：
   - 目标表模式：输入或选择目标表所在的数据库模式（如APPS、SYS等），支持手工填写
   - 临时表模式：输入或选择临时表创建位置（可与目标表不同，支持手工填写）
   - 目标表名：要更新的表名
   - 唯一标识列：Excel第1列对应的数据库列
   - 待修改列：点击「➕」添加列，点击「➖」删除列，顺序要与Excel一致
3. 选择Excel文件
4. 点击「👁 预览」查看数据
5. 点击「🔍 验证数据」检查Excel和数据库
6. 验证通过后点击「✅ 执行」开始更新
7. 在二次确认对话框中确认
8. 等待更新完成，查看结果

## 4. 功能详解

### 4.1 当前配置标签页

这是主要操作界面，包含：

#### 4.1.1 配置区域

- **目标表模式**：输入或选择目标表所在的数据库模式（支持手工填写，可点击⚙配置选项）
- **临时表模式**：输入或选择临时表所在的数据库模式（可与目标表不同，支持手工填写，可点击⚙配置选项）
- **目标表名**：输入要更新的数据库表名
- **唯一标识列**：Excel第1列对应的数据库列名，用于匹配记录
- **待修改列**：
  - 可以添加多个列
  - 点击「➕」添加列
  - 点击「➖」删除列
  - 顺序要与Excel一致

#### 4.1.2 Excel文件区域

- **选择文件**：点击「浏览」选择Excel文件
- **预览**：查看Excel前50行数据
- **提示**：
  - 最大10MB
  - 最多10万行
  - 使用.xlsx格式

#### 4.1.3 预览区域

- 显示Excel前50行数据
- 方便检查数据正确性
- 数据量大时提示「还有更多行」

#### 4.1.4 操作按钮

- **🔍 验证数据**：验证Excel结构和数据库表/列，全部通过后启用执行按钮
- **✅ 执行**：开始更新操作（初始禁用，验证通过后启用）
- **🗑 清空**：清空表单

### 4.2 操作日志标签页

- 显示所有操作日志
- 按时间倒序排列
- 日志级别：
  - INFO：信息
  - SUCCESS：成功（绿色）
  - WARNING：警告（黄色）
  - ERROR：错误（红色）

- **导出日志**：导出所有日志
- **导出失败记录**：导出更新失败的记录
- **清空日志**：清空当前显示

### 4.3 数据库连接标签页

- 连接下拉框：选择已保存的连接
- 测试连接：测试选中的连接
- 添加连接：添加新的数据库连接
- 删除连接：删除当前选中的连接
- 连接信息显示区域：显示当前连接的详细信息

### 4.4 历史记录标签页

- 显示所有更新操作记录
- 包含：时间、表名、总数、成功数、失败数、状态
- 支持刷新
- 支持批量删除

### 4.5 状态栏

从左到右依次显示：

1. **连接名称**（加粗）：当前选中的数据库连接
2. **用户**：当前数据库用户
3. **数据库**：当前连接的数据库
4. **连接状态**：指示灯 + 文字
   - 🔴 未连接
   - 🟢 已连接
5. **操作状态**：当前正在执行的操作
6. **操作系统版本**（最右侧）：如 Windows 10 (64bit) / Linux 6.8.0，服务器版加 [服务器版] 标记

### 4.6 主题切换

系统提供三套主题风格，每套均支持浅色/深色模式，共六种视觉方案。**默认风格为深墨琥珀**。

**风格按钮（位于顶部控制栏"主题:"标签之后）：**
- 点击 `深墨🖥` 切换到深墨琥珀（深墨蓝 + 琥珀金，Frontend Design 风格，默认）
- 点击 `Idea💡` 切换到 Idea 蓝色（IntelliJ IDEA 风格）
- 点击 `清爽✨` 切换到清爽浅色（清新蓝白，简约现代）

**深浅色按钮（位于风格按钮右侧）：**
- `🌙 深色模式` — 点击后切换到当前风格的深色变体
- `☀️ 浅色模式` — 点击后切换到当前风格的浅色变体

**按钮选中态：** 当前风格按钮背景使用 `primary` 主色高亮，与未选中按钮形成视觉区分。

**持久化：** 主题设置自动写入 `config.json` 的 `theme_style` / `theme_dark` 字段；下次启动程序自动恢复。

### 4.7 快捷键

- **Ctrl + S**：保存当前配置
- **← / →**：切换标签页（循环切换：当前配置 → 操作日志 → 数据库连接 → 历史记录）
- **↑ / ↓**：纵向滚动当前标签页内容（支持日志文本、历史记录表格等可滚动控件）

### 4.8 配置场景

配置场景功能允许您保存常用的配置组合，下次使用时可直接加载，无需手工填写。

**使用场景：**
- 经常对同一张表进行批量更新
- 需要更新多个相同的列
- 固定的数据库连接和模式

**操作步骤：**

1. **保存场景**
   - 填写好目标表名、唯一标识列、待修改列等配置
   - 点击"💾 保存为场景"按钮
   - 输入场景名称（必填，不超过100字符）和描述（可选）
   - 点击"保存"

2. **加载场景**
   - 从下拉列表选择目标场景
   - 点击"📂 加载"按钮
   - 配置将自动填充到对应字段

3. **删除场景**
   - 从下拉列表选择要删除的场景
   - 点击"🗑 删除"按钮
   - 确认删除

**场景字段：**
- 连接名称（可选）
- 目标表名
- 唯一标识列
- 待修改列列表
- 目标表模式
- 临时表模式（可与目标表不同）
- 描述

**注意事项：**
- 场景名称不能为空
- 场景名称不能超过100字符
- 同名场景会提示覆盖确认

## 5. 常见问题

### 5.1 安装问题

**Q: 启动时提示找不到Oracle客户端？**
A: 请确认已安装Oracle Instant Client，并配置了环境变量PATH。

**Q: 中文显示乱码？**
A: 设置环境变量：`NLS_LANG=SIMPLIFIED CHINESE_CHINA.AL32UTF8`

### 5.2 连接问题

**Q: 测试连接失败怎么办？**
A: 请检查：
1. 网络是否能连接到数据库服务器
2. 主机地址、端口、服务名是否正确
3. 用户名密码是否正确
4. 数据库是否允许远程连接

**Q: 连接超时？**
A: 检查防火墙设置，确认1521端口（或其他端口）已开放。

### 5.3 Excel问题

**Q: Excel导入失败？**
A: 请检查：
1. 是否使用提供的模板格式
2. 第一列是否是唯一标识，不能为空
3. 文件大小是否超过10MB
4. 行数是否超过10万行
5. v2.8.0 新增：CSV/JSON 文件支持流式读取，可达千万行

**Q: 提示重复键？**
A: Excel第1列有重复值，请检查并去重。

### 5.4 更新问题

**Q: 更新失败了，数据会怎么样？**
A: 更新失败时会自动回滚到初始状态，不用担心数据丢失。但是会保留备份表供检查。

**Q: 如何查看更新失败的记录？**
A: 在「操作日志」标签页点击「导出失败记录」。

**Q: 更新成功后发现改错了怎么办？**
A: 查看日志中的备份表名，手工从备份表恢复数据。

### 5.5 性能问题

**Q: 大数据量更新很慢怎么办？**
A: 建议分批处理，每批不超过1万条。v2.8.0 默认使用 MERGE INTO 模式，性能较逐行 UPDATE 提升 10x~100x。

### 5.6 帮助手册问题

**Q: 打开 CHM 帮助手册显示空白或"已取消导航"？**
A: 这是 Windows 安全机制导致的。当 CHM 文件从互联网下载或从 GitHub 下载时，Windows 会附加 Zone.Identifier 安全标记阻止内容显示。

**解决方法（按推荐顺序）：**

1. **从 ZIP 包解压（推荐）** — 解压 `OracleBatchUpdater_UserManual.zip`，ZIP 格式不保留 NTFS 安全标记，解压后自动解除锁定
2. **运行修复脚本** — 双击 `chm_unblock.bat`（Windows 7）或右键 `chm_unblock.ps1` → "使用 PowerShell 运行"（Windows 10/11）
3. **手动解除** — 右键 .chm 文件 → 属性 → 在"常规"选项卡底部勾选「解除锁定」→ 确定

**Q: CHM 文件在共享文件夹中打不开？**
A: Windows 默认阻止从网络驱动器（UNC 路径）打开 CHM 文件。请将 CHM 复制到本地磁盘（如 C:\ 或 D:\），然后解除锁定。如果必须在网络共享上使用，需要管理员权限修改注册表：
```
reg add "HKLM\SOFTWARE\Microsoft\HTMLHelp\1.x\ItssRestrictions" /v MaxAllowedZone /t REG_DWORD /d 1 /f
```
注意：修改注册表可能降低系统安全性，不建议在生产环境使用。

**Q: CHM 文件路径包含 # 号无法打开？**
A: CHM 格式不支持路径中包含 `#` 字符。请将文件移动到不含 # 的路径再打开。

### 5.7 EXE 启动问题

**Q: 双击 exe 文件弹出 Windows 安全警告，确认后无法打开？**
A: 这是 Windows SmartScreen 或 Zone.Identifier 下载标记导致的。解决方法（按推荐顺序）：
1. 右键 exe → 属性 → 在"常规"选项卡底部勾选「解除锁定」→ 确定
2. 将 exe 放在不含中文和特殊字符的短路径中（如 `C:\Tools\OracleBatchUpdater.exe`）
3. 如弹出"Windows 保护了你的电脑"蓝色对话框，点击「更多信息」→「仍要运行」

**Q: 弹出 "启动失败 - 缺少依赖" 错误对话框？**
A: 表示 PyInstaller 打包的 exe 找不到必要的 Python 模块。请检查：
1. `src/` 目录是否与 exe 在同一目录下
2. 是否安装了 Python 3.7+ 环境和所有依赖：`pip install -r requirements.txt`
3. 如以上都正常，尝试以开发模式运行：`python main.py`

**Q: 弹出 "启动失败" 错误，显示 `TclError`？**
A: 这通常发生在：
- Linux 服务器上缺少图形界面（`$DISPLAY` 环境变量未设置）
- 远程桌面/SSH 会话中无 X11 转发
- 解决方法：在本地 Windows 桌面环境下运行，或配置 X11 转发

## 6. v2.8.0 新增功能详解

### 6.1 多格式数据导入

v2.8.0 起支持 5 种数据格式：

| 格式 | 扩展名 | 最大行数 | 读取方式 |
|------|--------|----------|----------|
| Excel 2007+ | .xlsx | 10 万 | 全部加载 |
| Excel 97-2003 | .xls | 10 万 | 全部加载 |
| CSV | .csv | 1000 万 | 流式读取 |
| JSON 数组 | .json | 1000 万 | 流式读取 |
| JSON Lines | .jsonl | 1000 万 | 流式读取 |

**命令行示例：**
```bash
# CSV
python -m src.cli update --connection DEV --table EMPLOYEE \
    --file data.csv --key-column EMP_ID --update-columns NAME

# JSON
python -m src.cli update --connection DEV --table EMPLOYEE \
    --file data.json --key-column EMP_ID --update-columns NAME
```

### 6.2 CLI 命令行模式

v2.8.0 新增 5 个 CLI 子命令：

```bash
python -m src.cli update        # 执行批量更新
python -m src.cli connections   # 列出连接配置
python -m src.cli templates     # 列出场景模板
python -m src.cli verify-audit  # 验证审计日志完整性
python -m src.cli version       # 显示版本信息
```

退出码：`0=成功, 1=参数错误, 2=连接失败, 3=验证失败, 4=部分失败, 5=全部失败`

### 6.3 报表统计

v2.8.0 新增 `ImportStats` 模块，自动从历史日志生成 7 维度统计报表：

| 维度 | 方法 | 说明 |
|------|------|------|
| 总体 | `overall_summary()` | 操作次数、成功率、平均耗时、吞吐量 |
| 数据质量 | `data_quality_metrics()` | 完整度、准确性、丢失风险、A-F 等级 |
| Schema | `group_by_schema()` | 按数据库 Schema 统计 |
| 表 | `group_by_table()` | 按目标表统计 Top N |
| 时间 | `group_by_time_bucket()` | 日/小时/周几 三种时间桶 |
| 错误 | `error_distribution()` | ORA 错误码频率分布 |
| 状态 | `status_distribution()` | success / partial / fail 占比 |

**Python 调用：**
```python
from src.import_stats import ImportStats

stats = ImportStats()

# 30 天报表
summary = stats.overall_summary(days=30)
quality = stats.data_quality_metrics(days=30)

# 导出 HTML / JSON / 文本
stats.export_report("report.html", days=30, fmt="html")
stats.export_report("report.json", days=30, fmt="json")
```

### 6.4 操作员认证（高风险操作）

- 系统提供 4 种角色：`operator` / `approver` / `auditor` / `admin`
- 生产环境或 >1000 行的批量操作会被识别为**高风险**
- 高风险操作需要**双人审批**（申请人 ≠ 审批人）
- 审批令牌 30 分钟内有效，6 位数字

- **钉钉机器人** — 配置 webhook URL
- **企业微信机器人** — 配置 webhook URL
- **通用 Webhook** — 自定义 JSON POST
- **邮件** — SMTP + TLS

配置方式：将 `notification.json` 放在项目根目录：
```json
{
```

## 7. 最佳实践

### 7.1 操作前准备

1. 在测试环境先验证
2. 备份重要数据
3. 检查Excel数据正确性
4. 确认数据库账号权限
5. 高风险操作申请双人审批

### 7.2 数据更新建议

1. 先小批量测试（几十条数据）
2. 确认没问题再全量更新
3. 操作期间不要关闭程序
4. 保存更新日志
5. 启用通知系统，实时获知结果

### 7.3 Excel数据建议

1. 使用提供的模板
2. 第一列唯一标识不能为空
3. 数据类型要与数据库一致
4. 避免特殊字符和长文本
5. 使用.xlsx格式

### 7.4 日常维护建议

1. 定期清理历史记录
2. 定期备份配置
3. 保存重要的审计日志
4. 关注日志中的错误和警告
5. 每月运行 `python -m src.cli verify-audit` 验证审计完整性
6. 每月运行 `BackupManager.cleanup_old_backups()` 清理过期备份
7. 每季度运行 `DiagnosticsCollector.export_diagnostics()` 收集诊断信息
