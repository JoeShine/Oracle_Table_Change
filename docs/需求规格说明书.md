## 1. 项目概述

### 1.1 项目背景

在企业级应用开发和维护过程中，经常需要对Oracle数据库中的大量数据进行批量更新操作。传统的SQL脚本更新方式存在以下问题：

- 需要编写复杂的SQL脚本，开发效率低
- 对技术人员要求高，普通业务人员难以操作
- 缺乏有效的数据验证和备份机制
- 更新过程不可控，出错后难以回滚
- 操作缺乏审计追踪

为了解决上述问题，开发本工具以提供一个简单易用、安全可靠的Oracle数据批量更新解决方案。

### 1.2 项目目标

- 提供图形化界面，降低操作门槛
- 实现Excel数据导入和批量更新
- 提供完善的备份和回滚机制
- 支持多列同时更新
- 提供操作审计和日志记录
- 支持历史数据查询和管理
- 提供美观的UI和流畅的用户体验

### 1.3 项目范围

#### 1.3.1 包含功能

- Oracle连接管理配置和管理
- Excel数据导入和验证
- 数据预览和数据检查
- 批量数据更新（支持多列）
- 自动数据备份
- 失败回滚机制
- 运行日志记录和导出
- 历史数据管理
- 审计日志记录
- 三套主题风格（默认深墨琥珀，另含 Idea 蓝色、清爽浅色，每套 30 个配色键）+ 深浅色模式切换 + 启动自动恢复
- Schema 下拉选项可配置，支持手工填写
- 数据验证步骤（先验证后执行）

#### 1.3.2 不包含功能

- 数据库表结构修改
- 大数据量（超过10万条）的批量更新
- 分布式数据库支持
- 实时数据同步
- 数据库性能优化

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 要求 |
|-----|------|
| 启动时间 | < 3秒 |
| 连接建立时间 | < 5秒 |
| Excel解析速度 | 10000条/秒 |
| 数据更新速度 | 5000条/秒 |
| 界面响应时间 | < 0.2秒 |

### 3.2 可靠性需求

- 数据更新成功率 > 99%
- 备份成功率 100%
- 回滚成功率 100%
- 日志写入成功率 100%
- 程序崩溃概率 < 0.1%

### 3.3 安全性需求

- 数据库密码以 Base64 编码存储
- 操作前必须二次确认
- 审计日志不可篡改
- 支持操作追踪

### 3.4 兼容性需求

| 环境 | 要求 |
|-----|------|
| 操作系统 | Windows 7 及以上 |
| Python | Python 3.7+ |
| Oracle | Oracle 11g、12c、19c |
| Excel格式 | .xlsx、.xls |
| 屏幕分辨率 | 1024x768 及以上 |

### 3.5 可维护性需求

- 代码结构清晰，模块化设计
- 有完整的注释和文档
- 易于功能扩展
- 提供开发和部署文档

## 5. 约束条件

1. 需要安装Oracle Instant Client
2. 网络连接需正常访问Oracle数据库
3. 用户需要有数据库表的SELECT、INSERT、UPDATE、DELETE权限
4. 程序需要以管理员权限运行（某些环境）

## 6. 验收标准

### 6.1 功能验收

- [ ] 所有功能模块正常运行
- [ ] Excel导入和更新功能正常
- [ ] 备份和回滚功能正常
- [ ] 日志记录功能正常

### 6.2 性能验收

- [ ] 启动时间 < 3秒
- [ ] 更新速度 > 3000条/秒
- [ ] 界面流畅无卡顿

### 6.3 安全验收

- [ ] 密码以 Fernet AES-GCM 加密存储（v2.8.0 升级）
- [ ] 标识符白名单校验防止 SQL 注入（v2.8.0 升级）
- [ ] 审计日志 HMAC-SHA256 链式签名防篡改（v2.8.0 升级）
- [ ] 单事务回滚语义（v2.8.0 升级）
- [ ] 9 类结构化异常体系（v2.8.0 升级）
