2.1 系统要求

配置项最低要求推荐配置
操作系统Windows 7 / Windows Server 2008 R2Windows 10+ / Windows Server 2016+

2.2 安装方式

方式一：exe 打包（推荐）

1

下载程序

下载 DBForge_v2.8.0_linux-x86_64.tar.gz（Linux）或 DBForge.exe（Windows）

2

解压运行

Linux：tar -xzf DBForge_v2.8.0_linux-x86_64.tar.gz && ./DBForge

Windows：双击 DBForge.exe 即可运行

方式二：便携版

1

下载便携版

下载 DBForge_Portable_v2.8.0.zip

2

解压即用

解压到任意目录，双击 DBForge_Portable.bat（Windows）或运行 ./DBForge_Portable.sh（Linux）

便携版优势：
  • 无需管理员权限
  • 可放在 U 盘运行
  • 数据完全隔离，配置文件独立存储
  • 支持 Windows 7 / Server 2008 R2 等老旧系统

方式三：Docker 部署

注意：Docker 方式仅适用于 Windows 10+ / Windows Server 2016+ / Linux 系统。 
# 构建并启动
docker-compose up -d

# 浏览器访问
http://localhost:6080

2.3 Oracle 客户端配置

重要说明：使用 Easy Connect 方式，无需配置任何文件！直接在工具界面输入连接参数即可。

方式 A：使用已安装的 Oracle 客户端（推荐）

如果服务器已安装 Oracle 数据库或客户端：

  • 无需额外安装 Instant Client
  • 无需配置 tnsnames.ora
  • 直接在工具界面输入连接参数即可

方式 B：安装 Oracle Instant Client（可选）

1

下载 Instant Client

访问 Oracle 官网下载对应操作系统版本（Basic 或 Basic Light）

2

解压到目录

Windows：C:\oracle\instantclient_19_8

Linux：/opt/oracle/instantclient_19_8

3

配置环境变量

Windows：在系统环境变量 PATH 中添加 Instant Client 目录

Linux：export LD_LIBRARY_PATH=/opt/oracle/instantclient_19_8:$LD_LIBRARY_PATH

2.3.1 PyMySQL 安装 [v2.9.0+]

用于连接 MySQL 数据库的 Python 驱动库。

Windows / Linux / macOS

pip install PyMySQL
验证安装： 
python -c "import pymysql; print('PyMySQL', pymysql.__version__)"
注意：MySQL 服务器需开启远程连接权限，执行： 
GRANT ALL PRIVILEGES ON *.* TO 'username'@'%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;

2.3.2 ODBC Driver 17 for SQL Server 安装 [v2.9.0+]

用于连接 MS SQL Server 数据库的驱动。需要同时安装系统级 ODBC 驱动与 Python 级 pyodbc 库。

Windows

1

下载并安装 ODBC Driver 17

从微软官网下载：msodbcsql.msi，运行安装向导

2

安装 pyodbc

pip install pyodbc

Linux（Ubuntu / Debian）

# 添加微软 GPG 公钥
curl https://packages.microsoft.com/keys/microsoft.asc | apt-key add -

# 添加微软 apt 仓库
curl https://packages.microsoft.com/config/ubuntu/20.04/prod.list > /etc/apt/sources.list.d/mssql-release.list

# 安装驱动
sudo apt-get update
sudo ACCEPT_EULA=Y apt-get install msodbcsql17 unixodbc-dev

# 安装 Python 库
pip install pyodbc

Linux（CentOS / RHEL）

sudo su
curl https://packages.microsoft.com/config/rhel/7/prod.repo > /etc/yum.repos.d/mssql-release.repo
exit
sudo yum remove unixODBC-utf16 unixODBC-utf16-devel
sudo ACCEPT_EULA=Y yum install msodbcsql17 unixODBC-devel
pip install pyodbc

macOS

brew tap microsoft/mssql-release https://github.com/Microsoft/homebrew-mssql-release
brew update
HOMEBREW_NO_ENV_FILTERING=1 ACCEPT_EULA=Y brew install msodbcsql17 mssql-tools
pip install pyodbc
验证驱动： 
python -c "import pyodbc; print(pyodbc.drivers())"
输出中应包含 ODBC Driver 17 for SQL Server。
SQL Server 注意： 需确保 SQL Server 已启用 TCP/IP 协议（默认端口 1433），防火墙允许远程连接，并将 SQL Server Browser 服务启用。

2.4 帮助手册安全设置（重要）

Windows 安全警告：从互联网下载或从 GitHub 下载的 CHM 帮助手册， Windows 会自动附加安全标记（Zone.Identifier），导致打开后显示空白页或"已取消导航"。 这是 Windows 的正常安全机制，需要手动解除锁定。

方法一：使用 ZIP 包（推荐）

直接解压 DBForge_UserManual.zip，ZIP 格式不保留 Windows 安全标记，解压后即可正常打开。

方法二：运行修复脚本

操作系统脚本使用方法
Windows 7chm_unblock.bat双击运行
Windows 10 / 11chm_unblock.ps1右键 → "使用 PowerShell 运行"

方法三：手动解除锁定

1

右键文件

右键点击 DBForge_UserManual.chm → 属性

2

解除锁定

在"常规"选项卡底部，找到安全提示，勾选「解除锁定」复选框

3

确认

点击确定，然后正常打开 CHM 文件

提示：如果 CHM 文件在共享文件夹（网络驱动器）上，请先复制到本地磁盘（C:\ 或 D:\）再操作。 CHM 格式不支持从网络路径打开。
