2. 安装配置

2.1 系统要求

配置项最低要求推荐配置
操作系统Windows 7 / Windows Server 2008 R2Windows 10+ / Windows Server 2016+
跨平台支持macOS / Linux / 麒麟 V10
内存2 GB4 GB 以上
硬盘500 MB1 GB 以上
Oracle 客户端Oracle Instant Client 19+已安装 Oracle 数据库客户端
提示：使用 Easy Connect 方式连接数据库，无需配置 tnsnames.ora 文件，简化了部署流程。

2.2 安装方式

方式一：exe 打包（推荐）

1

下载程序

下载 OracleBatchUpdater_v2.8.0_linux-x86_64.tar.gz（Linux）或 OracleBatchUpdater.exe（Windows）

2

解压运行

Linux：tar -xzf OracleBatchUpdater_v2.8.0_linux-x86_64.tar.gz && ./OracleBatchUpdater

Windows：双击 OracleBatchUpdater.exe 即可运行

方式二：便携版

1

下载便携版

下载 OracleBatchUpdater_Portable_v2.8.0.zip

2

解压即用

解压到任意目录，双击 OracleBatchUpdater_Portable.bat（Windows）或运行 ./OracleBatchUpdater_Portable.sh（Linux）

便携版优势：
  • 无需管理员权限
  • 可放在 U 盘运行
  • 数据完全隔离，配置文件独立存储
  • 支持 Windows 7 / Server 2008 R2 等老旧系统

方式三：Docker 部署

注意：Docker 方式仅适用于 Windows 10+ / Windows Server 2016+ / Linux 系统。 
# 构建并启动
docker-compose up -d

# 浏览器访问
http://localhost:6080

2.3 Oracle 客户端配置

重要说明：使用 Easy Connect 方式，无需配置任何文件！直接在工具界面输入连接参数即可。

方式 A：使用已安装的 Oracle 客户端（推荐）

如果服务器已安装 Oracle 数据库或客户端：

  • 无需额外安装 Instant Client
  • 无需配置 tnsnames.ora
  • 直接在工具界面输入连接参数即可

方式 B：安装 Oracle Instant Client（可选）

1

下载 Instant Client

访问 Oracle 官网下载对应操作系统版本（Basic 或 Basic Light）

2

解压到目录

Windows：C:\oracle\instantclient_19_8

Linux：/opt/oracle/instantclient_19_8

3

配置环境变量

Windows：在系统环境变量 PATH 中添加 Instant Client 目录

Linux：export LD_LIBRARY_PATH=/opt/oracle/instantclient_19_8:$LD_LIBRARY_PATH
