5. 常见问题

5.1 安装问题

Q: 启动时提示找不到 Oracle 客户端？

A: 请确认已安装 Oracle Instant Client，并配置了环境变量 PATH。如果服务器已安装 Oracle 数据库，通常无需额外安装 Instant Client，系统会自动检测。

Q: 中文显示乱码？

A: 设置环境变量：NLS_LANG=SIMPLIFIED CHINESE_CHINA.AL32UTF8

5.2 连接问题

Q: 测试连接失败怎么办？

A: 请逐项检查：
  1. 网络是否能连接到数据库服务器
  2. 主机地址、端口、服务名是否正确
  3. 用户名密码是否正确
  4. 数据库是否允许远程连接

Q: 连接超时？

A: 检查防火墙设置，确认 1521 端口（或其他端口）已开放。

5.3 Excel 问题

Q: Excel 导入失败？

A: 请检查：
  1. 是否使用提供的模板格式
  2. 第一列是否是唯一标识，不能为空
  3. 文件大小是否超过 10 MB
  4. 行数是否超过 10 万行

Q: 提示重复键？

A: Excel 第 1 列有重复值，请检查并去重。

5.4 更新问题

Q: 更新失败了，数据会怎么样？

A: 更新失败时会自动回滚到初始状态，不用担心数据丢失。但是会保留备份表供检查。

Q: 如何查看更新失败的记录？

A: 在「运行日志」标签页点击「导出失败记录」。

Q: 更新成功后发现改错了怎么办？

A: 查看日志中的备份表名，手工从备份表恢复数据。

5.5 性能问题

Q: 大数据量更新很慢怎么办？

A: 建议分批处理，每批不超过 1 万条。可以使用 Excel 的筛选功能拆分数据。

Q: 最大支持多少条数据？

A: 单次最多支持 10 万行数据。超过此限制，建议分批次执行。v2.8.0 起 CSV/JSON 格式支持流式读取，可达千万行。

5.6 帮助手册问题

Q: 打开 CHM 帮助手册显示空白或"已取消导航"？

A: 这是 Windows 安全机制导致的。当 CHM 文件从互联网下载或从网络传输时，Windows 会附加 Zone.Identifier 标记阻止内容显示。

解决方法（推荐）：
1. 从 ZIP 包解压：解压旁边的 DBForge_UserManual.zip，ZIP 格式不保留安全标记，解压后自动解除锁定
2. 运行修复脚本：双击 chm_unblock.bat（Windows 7）或右键 chm_unblock.ps1 → "使用 PowerShell 运行"（Windows 10/11）
3. 手动解除：右键 .chm 文件 → 属性 → 勾选「解除锁定」→ 确定

Q: CHM 文件在共享文件夹中打不开？

A: Windows 默认阻止从网络驱动器打开 CHM 文件。请将 CHM 文件复制到本地磁盘（如 C:\ 或 D:\），然后解除锁定。如果必须在网络共享上使用，需要管理员修改注册表 HKLM\SOFTWARE\Microsoft\HTMLHelp\1.x\ItssRestrictions\MaxAllowedZone 值为 1（不推荐）。

Q: CHM 文件路径包含 # 号无法打开？

A: CHM 格式不支持路径中包含 # 字符。请将文件移动到不含 # 字符的路径。

5.7 MySQL 常见问题 [v2.9.0+]

Q: MySQL 连接提示 "No module named 'pymysql'"？

A: PyMySQL 驱动尚未安装。请运行 pip install PyMySQL 安装驱动后重启 DBForge。详情见「安装配置 → 2.3.1 PyMySQL 安装」。

Q: MySQL 连接提示 "Host 'xxx' is not allowed to connect to this MySQL server"？

A: MySQL 账号没有开启远程访问权限。请在 MySQL 服务端执行： 
GRANT ALL PRIVILEGES ON *.* TO 'username'@'%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;
其中 '%' 表示允许任意 IP 访问，也可以限定为特定 IP。

Q: MySQL 中文列名/中文表名报错？

A: v2.9.0 起系统已自动使用反引号（`` ` ``）包裹标识符。如仍报错，请确认数据库字符集为 utf8mb4： 
SHOW VARIABLES LIKE 'character_set_%';
# 确保 character_set_server = utf8mb4

5.8 MS SQL Server 常见问题 [v2.9.0+]

Q: 连接 SQL Server 提示 "IM002: [Microsoft][ODBC Driver Manager] 未发现数据源名称并且未指定默认驱动程序"？

A: ODBC Driver 17 for SQL Server 尚未安装。请按「安装配置 → 2.3.2 ODBC Driver 17 for SQL Server 安装」指引下载安装驱动，并运行 python -c "import pyodbc; print(pyodbc.drivers())" 验证。

Q: 连接 SQL Server 提示超时或拒绝连接？

A: 请逐项排查：
  1. SQL Server 配置管理器中「SQL Server 网络配置 → 协议 → TCP/IP」是否已启用
  2. TCP/IP 属性中 IPAll 的 TCP 端口是否为 1433（或与配置一致）
  3. Windows 防火墙是否已允许 1433 端口入站规则
  4. SQL Server Browser 服务是否已启用（动态端口场景）
  5. 是否使用了实例名（如 SQLSERVER2019），此时端口需为动态端口

Q: SQL Server 表名含空格或中文列名报错？

A: v2.9.0 起系统已自动使用方括号（[ ]）包裹标识符。如仍报错，请确认 Excel 表头与数据库实际列名完全一致（区分大小写取决于数据库的 collation 配置）。
