图3-1：三步操作流程概览

3.1 三步上手

第一步：配置连接管理

0

选择数据库类型 [v2.9.0+]

在添加连接前，先从「数据库类型」下拉框选择目标数据库：

数据库驱动/库默认端口标识符包裹
Oracleoracledb (python-oracledb)1521"双引号"
MySQLPyMySQL3306`反引号`
MS SQL Serverpyodbc + ODBC Driver 171433[方括号]
1

点击左侧导航栏的「连接管理」

2

点击「+ 添加连接」按钮

3

填写连接信息

字段说明示例
数据库类型[v2.9.0+] Oracle / MySQL / MS SQL ServerOracle
连接名称给连接起个名字开发环境
主机地址数据库服务器 IP 地址192.168.1.100
端口数据库监听端口1521 / 3306 / 1433
服务名/数据库名Oracle 服务名 / MySQL 数据库名 / SQL Server 数据库名ORCL / mydb / master
用户名数据库账号scott / root / sa
密码数据库密码********
4

点击「测试连接」验证配置

5

点击「保存」保存配置

Easy Connect 连接字符串格式（Oracle）： 
host:port/service_name
示例：192.168.1.100:1521/ORCL
[v2.9.0+] MySQL 连接示例： 
host:port/database
示例：192.168.1.100:3306/employee_db
[v2.9.0+] MS SQL Server 连接示例： 
host:port/database
示例：192.168.1.100:1433/HRDB

第二步：准备 Excel 数据

1

使用提供的模板：DBForge_导入模板.xlsx

2

按格式填写数据

  • 第 1 列：唯一标识（如：员工 ID）
  • 第 2 列起：要更新的列
3

保存 Excel 文件

注意：空字段将保留目标表原值，不会被更新为 NULL。

Excel 数据示例：

EMP_IDEMP_NAMEAGEDEPT说明
1001张三（空）技术部AGE 为空，保留原值
1002李四30（空）DEPT 为空，保留原值
1003王五28财务部全部填写，全部更新
图3-2：Excel 数据导入与预览界面

第三步：执行更新

1

点击左侧导航栏的「当前配置」

2

填写配置

  • 目标表模式：输入或选择目标表所在的数据库模式（如 APPS、SYS 等），支持手工填写
  • 临时表模式：输入或选择临时表创建位置（可与目标表不同），支持手工填写
  • 目标表名：要更新的表名
  • 唯一标识列：Excel 第 1 列对应的数据库列
  • 待修改列：点击「➕」添加列，点击「➖」删除列，顺序要与 Excel 一致
3

选择 Excel 文件

4

点击「👁 预览」查看数据

5

点击「🔍 验证数据」检查 Excel 和数据库

6

验证通过后点击「✅ 执行」开始更新

7

在二次确认对话框中确认操作

8

等待更新完成，查看结果
