## 2. 部署前准备

### 2.1 获取安装包

方式一：从GitHub下载

```bash
# 访问：https://github.com/JoeShine/Oracle_Table_Change
# 下载：DBForge.zip
```

方式二：自行构建（见构建章节）

### 2.2 Oracle客户端配置（可选）

**重要说明：使用Easy Connect方式，无需配置任何文件！**

#### 方式A：使用已安装的Oracle客户端（推荐）

如果服务器已安装Oracle数据库或客户端（如Windows Server 2008 R2 + Oracle 11g）：

- **无需额外安装Instant Client**
- **无需配置tnsnames.ora**
- **无需配置sqlnet.ora**
- 直接在工具界面输入连接参数即可

#### 方式B：安装Oracle Instant Client（可选）

如果服务器未安装Oracle客户端：

1. 下载Oracle Instant Client
   - 地址：https://www.oracle.com/database/technologies/instant-client/downloads.html
   - 选择对应操作系统的版本（Basic包即可）

2. 解压到指定目录
   ```
   C:\oracle\instantclient_19_8
   ```

3. 配置环境变量（仅需PATH）
   ```
   PATH = C:\oracle\instantclient_19_8;%PATH%
   ```

4. **无需配置TNS_ADMIN或任何配置文件**

#### Easy Connect连接方式

连接字符串格式：
```
host:port/service_name
```

示例：
```
192.168.1.100:1521/ORCL
localhost:1521/ORCL.localdomain
oracle-server:1521/MYDB
```

在工具界面填写：
| 字段 | 内容 | 示例 |
|-----|------|------|
| 主机地址 | host | 192.168.1.100 |
| 端口 | port | 1521 |
| 服务名 | service_name | ORCL |

### 2.3 准备数据库账号

需要准备的权限：
- SELECT：查询表结构和数据
- INSERT：向临时表插入数据
- UPDATE：更新目标表
- CREATE TABLE：创建备份表和临时表
- DROP TABLE：删除临时表

## 4. 配置说明

### 4.1 配置文件位置

配置文件自动保存到程序所在目录：
```
{程序目录}/config.json
```

### 4.2 日志文件位置

日志文件保存到：
```
程序目录\logs\
```

日志文件命名规则：
- 普通日志：`update_YYYYMMDD_HHMMSS.log`
- 审计日志：`audit.log`
- 操作历史：`history.json`

### 4.3 主题配置

主题设置随 `config.json` 持久化，程序启动时自动恢复，**默认风格为深墨琥珀（terminal）**。

**`last_used` 字段：**

| 字段 | 类型 | 取值范围 | 默认值 | 说明 |
|------|------|----------|--------|------|
| `theme_style` | string | `idea` / `terminal` / `clean` | `terminal` | 主题风格 |
| `theme_dark` | bool | `true` / `false` | `false` | 是否为深色模式 |

**配置示例：**

```json
{
  "last_used": {
    "connection_name": "dev",
    "target_table": "EMP",
    "key_column": "EMP_ID",
    "update_column": "EMP_NAME",
    "schema": "APPS",
    "theme_style": "terminal",
    "theme_dark": false
  }
}
```

**修改方式：**
- **推荐**：在程序界面点击主题按钮（`Idea💡` / `深墨🖥` / `清爽✨` / `🌙 深色模式`）自动保存
- **手动**：直接编辑 `config.json` 中的 `theme_style` 与 `theme_dark` 字段（注意备份原文件）

**兼容性：**
- 旧版 config.json 不含 `theme_style` / `theme_dark` 时，程序按默认值 `terminal` / `false` 启动
- 取值不在 `idea`/`terminal`/`clean` 范围时，按 `terminal` 处理，不影响程序运行

## 5.3 便携版打包（推荐用于 Windows 7 / Server 2008 R2）

便携版打包方式适合 Windows 7 和 Windows Server 2008 R2 等不支持 Docker 的系统。

### 5.3.1 系统兼容性说明

| 发布方式 | Windows 7 | Windows Server 2008 R2 | Windows 10+ | Windows Server 2016+ |
|---------|-----------|------------------------|-------------|----------------------|
| exe打包 | ✅ 支持 | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| 便携版 | ✅ 支持 | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| Docker | ❌ 不支持 | ❌ 不支持 | ✅ 支持 | ✅ 支持 |

**注意：** Docker 需要 WSL 2 和 Hyper-V 支持，仅适用于 Windows 10 (Build 19041+) 和 Windows Server 2016+。

### 5.3.2 创建便携版

**步骤1：打包exe文件**

```bash
# Windows环境
package.bat
```

**步骤2：创建便携版**

```bash
# Windows环境
scripts\create_portable.bat
```

**输出目录结构：**

```
DBForge_Portable_v2.8.0/
├── App/                    应用程序
│   ├── DBForge.exe
│   ├── src/                源代码（备用）
│   └── requirements.txt
├── Data/                   数据目录
│   ├── logs/               日志
│   ├── backups/            备份
│   └── config/             配置
├── OracleClient/           Oracle客户端（可选）
├── DBForge_Portable.bat  启动脚本
└── README_Portable.txt     使用说明
```

### 5.3.3 使用便携版

**方式一：解压即用**

1. 解压 `DBForge_Portable_v2.8.0.zip` 到任意目录
2. 双击 `DBForge_Portable.bat` 启动

**方式二：完整便携版（包含Python）**

1. 下载 Python Embedded 版本
   ```
   https://www.python.org/ftp/python/3.11.x/python-3.11.x-embed-amd64.zip
   ```

2. 解压到 `App\python` 目录

3. 安装依赖
   ```
   App\python\python.exe -m pip install -r App\requirements.txt --target App\python\Lib
   ```

4. 复制 Oracle Instant Client 到 `OracleClient` 目录

5. 运行 `DBForge_Portable.bat`

### 5.3.4 便携版优势

| 特性 | 说明 |
|-----|------|
| 无需安装 | 解压即用，无需管理员权限 |
| 完全便携 | 可放在U盘、网络共享运行 |
| 数据隔离 | 所有数据保存在便携目录 |
| 系统兼容 | 支持 Windows 7 / Server 2008 R2 |

## 5.5 Docker 部署（仅适用于 Windows 10+ / Server 2016+）

Docker 部署方式适合服务器环境，支持浏览器访问 GUI 界面。

**重要：** Docker 方式不支持 Windows 7 和 Windows Server 2008 R2，请使用便携版或exe打包方式。

### 5.5.1 系统要求

| 软件 | 版本要求 |
|-----|---------|
| 操作系统 | Windows 10 (Build 19041+) / Windows Server 2016+ / Linux |
| Docker | 20.10+ |
| Docker Compose | 2.0+ |

### 5.5.2 快速部署

```bash
# 1. 克隆项目
git clone https://github.com/JoeShine/Oracle_Table_Change.git
cd Oracle_Table_Change

# 2. 构建镜像
docker-compose build

# 3. 启动服务
docker-compose up -d

# 4. 查看状态
docker-compose ps
```

### 5.5.3 访问方式

| 方式 | 地址 | 说明 |
|-----|------|------|
| 浏览器访问 | http://localhost:6080 | noVNC Web 界面，无需安装客户端 |
| VNC 客户端 | vnc://localhost:5900 | 使用 VNC Viewer 等客户端连接 |

### 5.5.4 常用命令

```bash
# 启动服务
docker-compose up -d

# 停止服务
docker-compose down

# 查看日志
docker-compose logs -f

# 重启服务
docker-compose restart

# 进入容器
docker-compose exec oracle-batch-updater bash
```

### 5.5.5 数据持久化

以下目录通过 Docker 卷挂载实现持久化：

| 容器路径 | 说明 |
|---------|------|
| `/app/config.json` | 配置文件 |
| `/app/logs` | 日志目录 |
| `/app/data` | 数据目录 |

### 5.5.6 环境变量配置

```yaml
environment:
  - DISPLAY=:0          # X11 显示
  - TZ=Asia/Shanghai    # 时区设置
```

### 5.5.7 资源限制

默认配置：
- CPU 限制：2 核
- 内存限制：2 GB

可在 `docker-compose.yml` 中调整。

### 5.5.8 镜像说明

Docker 镜像包含：
- Ubuntu 22.04 基础系统
- Python 3 + tkinter
- Oracle Instant Client 21.15
- TigerVNC + noVNC (浏览器访问支持)
- 中文字体 (Noto Sans CJK, WenQuanYi)

## 7. 故障排查

### 7.1 常见问题

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 启动失败 | 缺少依赖库 | 确认已安装Oracle Instant Client |
| 连接失败 | 网络问题 | 检查网络连接、主机地址、端口 |
| 连接失败 | 账号密码错误 | 检查用户名密码 |
| 中文乱码 | 编码问题 | 设置NLS_LANG环境变量 |
| Excel导入失败 | 文件格式错误 | 使用提供的模板 |
| 更新失败 | 权限不足 | 确认数据库账号权限 |

### 7.2 日志查看

1. 打开程序目录下的 `logs` 文件夹
2. 查看最新的日志文件
3. 搜索 ERROR 或 WARNING
