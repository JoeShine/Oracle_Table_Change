项目信息
───────────────────────────────────────────────────────────────────────────
项目名称：DBForge (Database Forge)
项目类型：C/S 架构桌面应用程序
目标平台：Windows 7/8/10/11, Windows Server 2008 R2/2012/2016/2019/2022
编程语言：Python 3.8+
GUI 框架：tkinter
数据库驱动：oracledb (Oracle) / pymysql (MySQL) / pyodbc (SQL Server)
打包工具：PyInstaller

项目位置
───────────────────────────────────────────────────────────────────────────
主目录：/workspace/Oracle_Table_Change
源码目录：src/
配置文件：config.json
日志目录：logs/
备份目录：backups/

模块说明
───────────────────────────────────────────────────────────────────────────
1. config_manager.py  - 配置管理（连接、配置保存、多数据库类型持久化）
2. logger.py          - 日志管理（记录、导出）
3. db_connection.py    - 连接管理（Oracle/MySQL/SQL Server 三种数据库的连接、查询、执行）
4. excel_handler.py    - Excel 处理（读取、验证、导出）
5. data_updater.py     - 数据更新（备份、方言自适应更新、清理）
6. gui.py             - 图形界面（所有用户交互）

使用方式
───────────────────────────────────────────────────────────────────────────
方式 1：运行 Python 源码
  $ pip install -r requirements.txt
  $ pip install pymysql pyodbc            # 多数据库额外依赖
  $ python main.py

方式 2：打包为 exe
  Windows: 运行 package.bat
  或: pyinstaller DBForge.spec --clean

方式 3：Docker 部署
  $ docker-compose up -d
  浏览器访问 http://localhost:6080

方式 4：验证安装
  Windows: 运行 verify.bat
  或: python test_all.py

部署说明
───────────────────────────────────────────────────────────────────────────
1. 打包 exe 后，将 dist 目录下的所有文件复制到目标电脑
2. 数据库客户端配置（按需）：
   - Oracle: 配置 Oracle Instant Client（oracledb thick 模式）或使用 thin 模式
   - MySQL : 无需系统客户端，pymysql 纯 Python 驱动
   - SQL Server: 安装 Microsoft ODBC Driver 17 for SQL Server
3. 直接运行 DBForge.exe
4. 无需安装 Python 环境

下一步
───────────────────────────────────────────────────────────────────────────
1. 在 Windows 环境中运行 package.bat 打包
2. 将打包后的文件部署到目标电脑
3. 按需求配置 Oracle Instant Client / MySQL / SQL Server 客户端
4. 运行程序并测试
