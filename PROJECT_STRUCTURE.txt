文件说明
═══════════════════════════════════════════════════════════════════

核心模块说明
───────────────────────────────────────────────────────────────

1. main.py
   - 程序入口点
   - 初始化 GUI 并启动主循环
   - 检测可用数据库驱动（oracledb / pymysql / pyodbc）

2. config_manager.py
   - 管理连接管理配置（支持多数据库类型字段）
   - 保存和加载用户配置
   - 自动保存最近使用的配置

3. logger.py
   - 日志记录功能
   - 支持 INFO / 成功 / 错误 / 警告 级别
   - 记录失败记录
   - 导出日志到文件

4. db_connection.py （v2.9.0 多数据库核心）
   - Oracle / MySQL / SQL Server 三连接管理管理
   - 执行 SQL 语句（方言自适应）
   - 获取表和列信息
   - 事务管理

5. excel_handler.py
   - 读取 Excel 文件
   - 验证 Excel 格式
   - 导出日志和失败记录到 Excel
   - 数据预览

6. data_updater.py （v2.9.0 多数据库核心）
   - 表备份功能（Schema / Database / 方括号/反引号适配）
   - 临时表管理（方言自适应 DDL）
   - Excel 数据导入
   - 数据更新执行（MERGE / ON DUPLICATE KEY UPDATE / UPDATE FROM）
   - 错误处理

7. gui.py
   - 图形用户界面
   - 连接管理配置面板（含数据库类型下拉：Oracle / MySQL / SQL Server）
   - 更新参数配置面板
   - Excel 数据预览
   - 进度显示
   - 失败记录弹窗

使用说明
═══════════════════════════════════════════════════════════════════

开发模式运行：
  python main.py

打包为 exe：
  Windows: 运行 package.bat
  或手动: pyinstaller DBForge.spec --clean

安装依赖：
  pip install -r requirements.txt
  pip install pymysql pyodbc          # 多数据库额外依赖（MySQL / SQL Server）

验证安装：
  Windows: 运行 verify.bat

Docker 部署：
  docker-compose up -d
  浏览器访问 http://localhost:6080
